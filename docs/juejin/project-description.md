# 镜选 · Eyewear Assistant

在线试戴眼镜，不用注册，不用下载 App。

## 能做什么

打开页面，开摄像头或者上传一张照片，从 73 款镜框里挑一副戴上去看看效果。可以按风格和颜色筛选缩小范围，拍下快照，并排放最多三张对比，省掉每次切换都要重新回忆的麻烦。

如果觉得模型偏大或者位置不对，页面里有缩放和上下微调，控件在预览下方，调完本机记住，这个校准对当前浏览器全局生效。不想开摄像头也不想传照片，可以用内置的中性人头先看各款轮廓。有自己的 GLB 文件，也可以直接导入试戴。

## 用途和边界

适合在拿定主意之前排除明显不合适的款式，或者对比几个候选。

这里展示的是视觉预览，73 款模型由参数化脚本生成，不包含真实镜框的测量数据，不能替代到实体店试戴和量尺寸。推荐筛选是按风格和颜色属性标签匹配，不是 AI 脸型分析或颜值评分。
